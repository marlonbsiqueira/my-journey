# Media files for "My Journey"

The slides reference media at **`images/…`** (a folder next to `index.html`).
Create that folder and drop your files using these exact names — each appears
automatically, replacing its placeholder:

```
images/initial.jpg              hero / background context
images/mi1.jpg                  personal introduction
images/logo1.jpg … logo6.jpg    company logos (Sandvik, Vale, Ally,
                                Meridian, Fundação Renova, Stellantis)
images/edu1.jpg … edu4.jpg      education
images/BR_video1.mp4 … 4.mp4    Brazil (helicopter, skydiving, hang gliding,
                                aerobatic flight)
images/US_video1.mp4            United States
images/world_travel.jpg         Europe / global travel
images/sports.jpg               sports & achievements
images/contact.jpg              thank-you portrait
```

Recommended: landscape images ~1600×900, square logos ~200×200, MP4 (H.264)
videos. This `public/images/` folder is an optional alternative location — if you
prefer it, update the paths in `src/data/journey.js` accordingly.
